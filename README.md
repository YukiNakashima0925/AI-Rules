# AI Rules

给 AI 编码代理使用的工作守则，适用于 DeepSeek Harness（DSH）等支持 `AGENTS.md` 约定的工具。

## 文件

- [`AGENTS.md`](AGENTS.md) — 守则正文，14 条

## 使用方式

放到工作区根目录，DSH 会在会话首次请求时自动注入：

```
<workspace>/AGENTS.md
```

对**所有**工作区生效，放到用户全局层：

```
~/.dsh/AGENTS.md
```

两者可叠加，项目级优先于全局。其他支持 `AGENTS.md` 的工具（如 Codex、Cursor）可直接复用。

## 设计原则

- 用中文写，便于长期人工维护
- 只写可执行的约束，不写空泛口号
- 每条都对应一个真实会出错的场景
- 精简，减少上下文开销
